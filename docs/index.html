Vehicle routing solver

Find short delivery routes for a fleet of vehicles that start and end at one or more depots and must not exceed their capacity. Everything runs in your browser; nothing is uploaded.

How to use this page
  1. Choose the customers. Use an example, generate random customers, or upload your own table (a CSV file with the columns x, y, demand).
  2. Press Solve. The solver tries several times, each with different random choices, and keeps improving the routes for a few seconds.
  3. Read the result. The map shows the best routes found (one colour per route, or per depot when there are several; squares are depots). Best cost is the total distance driven. The charts show how quickly the cost fell and how much the tries differ.

Switch to Expert to choose among 20 search methods, compare them at equal compute time, and set seeds, iterations and local-search operators. The Learn tab explains the models and methods.

1 · Instance

Public benchmark instances bundled with this site (sources and credits). X, CMT and Golden are single-depot; p and pr have several depots. CMT and Golden use unrounded distances, and some of them limit the route duration. Instances with more than about 500 customers are slow in the browser.

CSV table: one row per location with the columns x, y, demand. Rows with demand 0 are depots (or add a type column with depot). Distances are straight lines in the units of your coordinates. With the columns lat and lon instead of x and y, distances are great-circle distances in kilometres. Download a template.

Distance matrix: a square table with one row and one column per location, in the order of the rows of your CSV table (for example road distances or travel times from your own tool). It must be symmetric; the x and y columns then only place the points on the map and may be left out. Download a matching template. Nothing is uploaded: your files stay in your browser.

Also accepted: CVRPLIB .vrp (single depot; EUC_2D, or EXPLICIT with a full or triangular matrix; route-duration limit and service time are read) and Cordeau MDVRP files (p01…).

2 · Method and time

Each method gets the iteration budget that takes about the chosen compute time on this instance and machine (a short timing run decides it); the table reports the real times. The runs of every method use the same seeds.

Your own method (JavaScript)

Write a search method and compare it with the built-in ones at the same compute time: choose Custom (your code) in the method list, or tick it in the comparison. The code defines function customMethod(api, start) that returns a function performing one iteration; the example explains the interface.

Download the template

Your code runs in your browser only, in a separate worker without network access, and the Solver checks cost and feasibility of every solution itself. Results are labelled “Custom”. Run only code that you wrote or understand.

sd = sample standard deviation (n − 1). Time = compute time of the run inside its worker; runs in parallel share the machine, so a lone run can be faster. The best solution file lists one route per line: Route #k (depot d): customer ids.

The solver is an educational implementation that runs in your browser; for large instances or benchmark-quality results use HGS-CVRP, PyVRP or FILO. Best-known values are shown only where we could check them against a published table.
